Reach — A hybrid, B static melee. The discount lands on the single-target term only, because area is already priced into the AoE score itself. ranged 1.00 · hybrid 0.95 · mobile 0.95 crowd, 1.00 priority · static 0.85 crowd, 0.90 priority.

5 + 0 is worse than 3 + 3. A pair where one character wins the crowd fights and the other wins the boss fights has a passenger in every encounter. Split single-target against area, or one damage type against another, only when neither half has a dead fight — a fallback that is still useful is the whole condition.

Melee lock. Delete this callout if either character is ranged or hybrid. If neither is, say so here and apply the 0.9 crowd multiplier above: anything that kites, flies or holds a ledge is fought entirely on its terms, and the radar has no cell that says so.

Coverage and damage are two numbers, and each is counted once. Ranking pairs on the nine-axis total is damage-blind by accident — across a 135-pairing field the correlation between that total and delivered damage is 0.00, because the seven non-damage axes correlate negatively with it (−0.46) and cancel the damage block's +0.81. Read the seven-axis coverage and this table side by side; never sum all nine and call it a ranking.

A gate is satisfied only by Expertise, by proficiency on that character's primary ability, or by proficiency plus stacked boosts. Plain proficiency on a dump stat is a tick on the skill map and a failed check in the game — Religion is where this bites, because it keys off Intelligence and almost nothing in a duo runs Intelligence. Inspiration caps at 4, is shared across the party, and cannot fix a missing proficiency; passive Perception is the one row the bank never reaches, so it belongs on the high-Wisdom character with proficiency and Expertise, bought up front.
